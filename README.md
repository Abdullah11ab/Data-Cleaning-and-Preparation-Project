# Project 1: Data Cleaning & Preparation

## Project Goal
Clean a raw e-commerce dataset by handling missing values, duplicates, and incorrect data formats.

## Key Steps Executed
* **Handled Missing Values:** Filled blank coupons with 'No Coupon' and missing referrals with 'Direct'.
* **Duplicate Removal:** Verified and ensured no duplicate order records exist.
* **Format Standardization:** Corrected date formats (YYYY-MM-DD), adjusted text casing, and formatted price columns into standard currency/2-decimal values.
* **Data Preparation:** Cleaned column headers and auto-fitted layout for analytics readiness.
